# 教學駕駛艙

國小互動教學平台框架（不限科目），黑板粉筆風格。每個單元含翻頁簡報、動手操作、形成性評量、資訊圖表、教師提示，以及抽籤器、計時器、畫筆、QR code 等課堂工具。

- 首頁：https://kristysu701023-cyber.github.io/teaching-cockpit/
- 做新單元：複製 `templates/unit/` 到 `units/<英文名>/`，改裡面的 `UNIT` 內容，再到首頁 `index.html` 加一張卡片。詳見 `skills/teaching-cockpit/SKILL.md`。

改寫自 [math-cockpit](https://github.com/mathruffian-dot/math-cockpit)（MIT）。QR 產生器使用 [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)（MIT）。
